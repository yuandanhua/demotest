# 猜数字小游戏

一个简单有趣的浏览器猜数字游戏，帮助玩家练习逻辑思维和数字直觉。

## 项目简介

这是一个纯前端实现的猜数字游戏，玩家需要在 1-100 之间猜出一个随机生成的数字。游戏会根据玩家的猜测给出"大了"或"小了"的提示，帮助玩家逐步缩小范围直到猜中。

## 功能说明

- 随机生成 1-100 之间的整数作为目标数字
- 实时验证用户输入（范围、整数检查）
- 智能提示：告知玩家猜大了还是猜小了
- 猜测次数统计
- 通关后支持"再来一局"
- 响应式设计，支持移动端

## 安装步骤

### 方式一：直接使用（推荐）

直接在浏览器中打开 `index.html` 文件即可开始游戏。

### 方式二：本地服务器

```bash
# 使用 npm 启动本地服务器
npm install
npm run serve
```

### 方式三：全局安装（如果发布到 npm）

```bash
npm install -g guess-number-game
guess-number-game
```

## 使用示例

### 基本玩法

1. 在输入框中输入 1-100 之间的整数
2. 点击"提交猜测"或按回车键
3. 根据提示调整你的猜测
4. 猜中后可以看到用了多少次

### 示例截图

游戏开始时显示提示信息，输入数字后立即获得反馈。
