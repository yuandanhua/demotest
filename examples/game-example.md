# 猜数字游戏示例

本文档展示了猜数字游戏的典型使用场景。

## 示例一：二分法策略

使用二分法（Binary Search）可以最高效地猜中数字。

### 步骤演示

| 猜测 | 结果 | 剩余范围 |
|------|------|----------|
| 50 | 猜大了 | 1-49 |
| 25 | 猜小了 | 26-49 |
| 37 | 猜大了 | 26-36 |
| 31 | 猜小了 | 32-36 |
| 34 | 猜小了 | 35-36 |
| 35 | 猜小了 | 36 |
| 36 | 正确！| - |

使用二分法，最多 7 次即可猜中 1-100 之间的任何数字。

## 示例二：常见错误输入

游戏会友好地处理以下错误情况：

### 错误类型 1：超出范围
```
输入：0
提示：请输入 1-100 之间的整数

输入：101
提示：请输入 1-100 之间的整数
```

### 错误类型 2：非整数
```
输入：3.14
提示：请输入整数，不要输入小数
```

### 错误类型 3：非数字
```
输入：abc
提示：请输入一个有效的数字
```

## 示例三：游戏流程

1. **初始状态**
   - 显示标题"猜数字小游戏"
   - 提示"猜一个 1 到 100 之间的整数"
   - 猜测次数：0

2. **进行中**
   - 每次猜测后更新提示信息
   - 猜测次数递增
   - 输入框自动清空并聚焦

3. **通关**
   - 显示恭喜信息和猜测次数
   - 输入框和提交按钮禁用
   - 显示"再来一局"按钮

4. **重新开始**
   - 重置所有状态
   - 生成新的随机数字
